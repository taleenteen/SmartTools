🗂 จัดการหมวดหมู่

หมวดหมู่ในตัวมาจาก data.js ไม่สามารถแก้ไข ลบ หรือจัดเรียงได้ หมวดหมู่กำหนดเองสามารถเพิ่ม ลบ แก้ไข และจัดเรียงได้อย่างอิสระ

🔒 หมวดหมู่ในตัว

⚙️ หมวดหมู่กำหนดเอง (แสดงหลัง "วิดีโอรวม" ก่อน "อีเมล")

💡 เมื่อลบหมวดหมู่กำหนดเอง การ์ดทั้งหมดในหมวดหมู่นั้นจะถูกย้ายไปที่ "📦 ยังไม่ได้จัดหมวดหมู่" โดยอัตโนมัติ (ข้อมูลไม่สูญหาย) "📦 ยังไม่ได้จัดหมวดหมู่" เป็นหมวดหมู่กำหนดเองเช่นกัน สามารถลบได้อีกครั้ง (หลังยืนยันการ์ดข้างในจะถูกลบถาวร)

➕ เพิ่มหมวดหมู่

อนุญาตเฉพาะตัวอักษร ตัวเลข ขีดล่าง และยัติภังค์ เมื่อตั้งค่าแล้วสามารถใช้ #anchorของคุณ เพื่อข้ามไปยังหมวดหมู่นี้ได้โดยตรง เว้นว่างไว้เพื่อใช้ค่าเริ่มต้น

เมื่อเลือก จะทำงานเหมือนกับ "วิดีโอรวม": บนมือถือ/แท็บเล็ตจะแสดงเฉพาะ 4/6 การ์ดแรก และสามารถคลิกปุ่ม "ขยาย" เพื่อดูทั้งหมด บนเดสก์ท็อปจะแสดงทั้งหมด

🔒 เมื่อเลือก การ์ดทั้งหมดในหมวดหมู่นี้จะถูกเขียนลงใน data.js / KV ในรูปแบบเข้ารหัส AES-256-GCM
🔑 คีย์เข้ารหัสสร้างขึ้นจากรหัสผ่านเข้าสู่ระบบปัจจุบัน (PBKDF2 300,000 รอบ) ปัจจุบันยังไม่รองรับการตั้งรหัสผ่านแยกต่างหากสำหรับแต่ละหมวดหมู่
🔁 หากต้องการเปลี่ยน: ให้เปลี่ยนรหัสผ่านในแถบด้านบน → จากนั้นกด 💾 Save ทันที ข้อมูลเก่าจะถูกถอดรหัสด้วยรหัสผ่านเดิมแล้วเข้ารหัสใหม่ด้วยรหัสผ่านใหม่
⚠️ หากเปลี่ยนรหัสผ่านเข้าสู่ระบบแล้วไม่ได้กด Save ทันที ข้อมูลที่เข้ารหัสเดิมจะไม่สามารถปลดล็อกได้!

🔓 ปลดล็อกหมวดหมู่ที่เข้ารหัส

🔑 โปรดกรอกรหัสผ่านเข้าสู่ระบบของคุณ (ใช้สร้างคีย์ถอดรหัส) รหัสผ่านจะถูกเก็บไว้ชั่วคราวในแท็บเซสชันนี้เท่านั้น และจะไม่ถูกเขียนลงใน localStorage

🕐 ประวัติเวอร์ชันสำรอง

📡 ตั้งค่าแหล่งข้อมูลหน้าหลัก

ควบคุมว่าจะโหลดข้อมูลชุดใดเมื่อเข้าชม หน้าหลัก มีผล ทันที หลังแก้ไข โดยไม่ต้องปรับใช้ใหม่

☁️ โหมด KV ปัจจุบัน
ใช้ข้อมูลที่บันทึกจากหน้าตั้งค่านี้ (แนะนำ) หลังจากแก้ไขและบันทึกในหน้านี้ หน้าหลักจะอัปเดตทันที
📄 โหมด Static ปัจจุบัน
ใช้ไฟล์ data.js จากที่เก็บ GitHub จำเป็นต้องใช้ git push เพื่ออัปเดตหน้าหลัก
💡 หลังจากเปลี่ยนเป็น "Static" ข้อมูลที่บันทึกไว้ในหน้านี้จะยังคงอยู่ใน KV ไม่สูญหาย แต่หน้าหลักจะไม่นำไปใช้ เมื่อเปลี่ยนกลับเป็น "KV" ก็จะกลับมาใช้งานได้ตามเดิม

วางเนื้อหา data.js หรือเลือกไฟล์เพื่อนำเข้า

📤 ส่งออกตาราง

        
ส่งออกการ์ดทั้งหมดเป็นไฟล์ตาราง สามารถเปิดแก้ไขด้วย Excel / WPS / Numbers แล้วนำกลับเข้ามาผ่าน「📥 นำเข้าตาราง」


        

            
            
        


        

            
            
        

        
⚠️ หมวดหมู่ที่เข้ารหัสเมื่อส่งออกจะเป็นข้อความธรรมดา (Plaintext) ในไฟล์ CSV โปรดเก็บรักษาไฟล์อย่างระมัดระวัง หมวดหมู่ที่ยังไม่ได้ปลดล็อกจะถูกข้ามโดยอัตโนมัติ

        
📝 ฟิลด์ที่มี emoji (เช่น icon) โปรดแก้ไขด้วยโปรแกรมเอดิเตอร์ UTF-8 เช่น VS Code / Notepad++; การบันทึก CSV ด้วย Excel / WPS บนบางระบบอาจทำให้ emoji สูญหาย หากต้องการแก้ไขในโปรแกรมสเปรดชีต โปรดใช้「📤 ส่งออก XLSX」แทน


        

            📋 ดาวน์โหลดเทมเพลตเปล่า (ตามรูปแบบที่เลือก)
        


        

            📖 คำอธิบายฟิลด์ / การระบุประเภทแถว
            

        


        

            
            
        

    







    

        
📥 นำเข้าตาราง

        
รองรับไฟล์ .xlsx และ .csv การนำเข้าจะเขียนลงในตัวแก้ไขเท่านั้น จะไม่บันทึกทันที หลังตรวจสอบตัวอย่างเรียบร้อยแล้ว อย่าลืมคลิก「💾 Save」ด้วยตนเอง

        
📝 ฟิลด์ที่มี emoji (เช่น icon) โปรดแก้ไขด้วยโปรแกรมเอดิเตอร์ UTF-8 เช่น VS Code / Notepad++; การบันทึก CSV ด้วย Excel / WPS บนบางระบบอาจทำให้ emoji สูญหาย หากต้องการแก้ไขในโปรแกรมสเปรดชีต โปรดใช้「📤 ส่งออก XLSX」แทน
